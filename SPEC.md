# Projector Manager

Проекционный маппинг на домашнем проекторе: рисуем полигоны по реальным предметам на стене и заливаем их шейдерными анимациями, подогнанными под геометрию. Есть режим под музыку с авто-режиссёром.

## Запуск

```
pnpm install
pnpm dev        # http://localhost:5173 (доступ к аудиовходам работает только на localhost/HTTPS)
pnpm test       # rstest (unit)
pnpm test:e2e   # Playwright на системном Chrome (WebGL через swiftshader, фейковое аудиоустройство)
pnpm typecheck
pnpm build
```

Окно проектора: кнопка «Окно проектора» (маршрут `/output`) → перетащить на экран проектора → двойной клик (полный экран).

## Железо: проектор «А10» (WB 605279357)

LCD/LED, нативные **1280×720**, 16:9, HDMI + USB, встроенный Android, Wi-Fi/Bluetooth, AirPlay. «4K», «лазерный», «500 см» из описания — маркетинг. Реальная яркость низкая → работать в тёмной комнате. Тонкие линии на 720p дрожат, поэтому эффекты делаются с толстым контуром и мягким свечением.

Подключение Mac → проектор — только HDMI (AirPlay/Miracast дают задержку):
1. Проектор грузится в свой Android-лаунчер: пультом переключить источник на **HDMI** (самая частая причина «не получается»).
2. Переходник USB-C→HDMI должен поддерживать видео.
3. macOS: Дисплеи → проектор → режим **Расширить**, **1280×720 @ 60 Гц** (запасной вариант 1920×1080).
4. Цифровую трапецию (keystone) в меню проектора выключить: она ресайзит картинку.

## Стек

rsbuild, rstest (jsdom 26: jsdom 30 требует более новый Node), TypeScript (strict), React 19, `@gravity-ui/uikit`, `@tanstack/react-router`, effector + effector-react + patronum, PixiJS v8 (GLSL-шейдеры). Окна синхронизируются через `BroadcastChannel`.

Конвенции — документация команды (`frontend_arch`, `codestyle`): слои `app → pages → features → entities → shared`, модели-фабрики `createXxx(deps)` с DI и узкими типами зависимостей, `sample` вместо `.on`/`restore`, публичный API через `index.ts`, kebab-case файлы, без `any`/`!`/`as`/`enum`/`interface`/default export.

## Структура

```
src/
  app/                 провайдеры (Gravity ThemeProvider), роутер: / (редактор), /output (проектор)
  pages/
    editor/            композиция фич + lib/build-frame (сборка кадра)
    output/            окно проектора: рисует кадры из BroadcastChannel
  features/
    shape-editor/      рисование/правка полигонов, список, свойства, горячие клавиши
    playback/          режимы: Редактор / Показ / Авто / Blackout
    audio-analysis/    аудиовход (BlackHole и др.) или файл, полосы bass/mid/high, детектор бита, демо-бит
    auto-director/     выбор эффектов и палитр по геометрии и музыке
    stage/             рендер на PixiJS (по шейдеру на эффект, полигон как SDF)
    projector-output/  открытие окна и канал кадров
  entities/
    shape/             фигура, список, выбор, хранилище (localStorage через DI)
    effect/            каталог эффектов (GLSL)
  shared/
    contracts/         StageFrame, AudioReading
    config/            размеры сцены, лимиты
    lib/geometry, lib/color
```

Правило «горячих данных»: значения звука, меняющиеся каждый кадр, не проходят через effector и React — живут в замыкании `audio-analysis` и читаются циклом рендера. В effector только редкие события и состояние сцены. Кадр (`StageFrame`) собирается редактором каждый rAF и целиком уходит в окно проектора.

## Модель данных

`Shape`: `id`, `name`, `points[]` (координаты проектора 1280×720, ≤ 32 вершин), `effectId`, `color1`, `color2`, `speed`, `phase`. Хранится в localStorage (`projector-manager:shapes`).

## Эффекты (entities/effect)

Бегущий свет (`edge-trace`), Неон, Волны от края, Плазма, Сканер, Вспышка на бит, Искры, Радуга + сервисный `grid` (тонкий контур для подгонки по стене, показывается проектором в режиме «Редактор»). Эффект = тело GLSL-функции `vec3 effect(vec2 p, float d, float s)`: `d` — расстояние до контура (< 0 внутри), `s` — позиция вдоль периметра; доступны `uT`, `uSpeed`, `uPhase`, `uC1`, `uC2`, `uBass`, `uMid`, `uHigh`, `uBeat`, `uSize`, `uCen`.

## Музыка из любого приложения (macOS)

Браузер не умеет захватывать системный звук, поэтому используется виртуальная звуковая карта:
1. `brew install blackhole-2ch`.
2. Audio MIDI Setup → «+» → Multi-Output Device: отметить колонки/HDMI проектора и BlackHole 2ch. Системный вывод переключить на него (так музыка слышна и уходит в BlackHole).
3. В приложении открыть список «Источник звука» (при первом открытии браузер спросит доступ) и выбрать «BlackHole 2ch».

Альтернатива: «Файл…» — приложение само играет и анализирует трек.

## Авто-режим под музыку

- Раз в 8 битов — новый «лук»: палитра и эффекты. Большие фигуры (> 3% кадра) получают заливки, мелкие — линии.
- На каждый бит вспыхивает следующая фигура слева направо («эстафета»).
- Резкий рост громкости (дроп) → мгновенная смена лука и всплеск яркости.
- Без микрофона и файла крутится демо-бит 124 BPM.

## Риски

Яркость проектора; фокус и физическая трапеция; overscan (в меню проектора поставить «1:1/Исходный»); для реального бита нужен выбранный аудиовход или файл (иначе демо-бит); `BroadcastChannel` работает только между окнами одного origin и одного браузера.
